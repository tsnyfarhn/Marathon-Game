# Marathon Game
Marathon Game is a prototype racing game developed using Unreal Engine 4. It was created as part of my scientific writing project during my university studies in 2022.

## Main Menu
Main Menu can choose Singleplayer, Multiplayer (Local), Options, Exit Game.

## Singleplayer Mode
Singleplayer mode features the player racing against a CPU opponent, with various obstacles throughout the track.

## Multiplayer Mode
Multiplayer mode allows players to race against each other, using split-screen as the camera view, with various obstacles along the track.

## Options
Options can change screen resolution, anti aliasing, shadow quality, texture quality, volume, and can see button mapping.
