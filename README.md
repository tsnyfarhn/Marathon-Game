# Marathon Game
Marathon Game is a prototype racing game developed using Unreal Engine 4. It was created as part of my scientific writing project during my university studies in 2022.

## Main Menu
Main Menu can choose Singleplayer, Multiplayer (Local), Options, Exit Game.
